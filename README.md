# 🌦️ Real-Time Weather Dashboard 

A professional, high-performance web application that provides live weather updates for any city globally. Built with a focus on clean UI/UX and seamless API integration.

## 💎 Key Features
* *Live Data Fetching:* Integrates with *OpenWeatherMap API* to provide real-time temperature, humidity, and wind speed.
* *Dynamic Search:* Instant weather updates based on city name input.
* *Responsive Architecture:* Fully optimized for Desktop, Tablets, and Mobile devices.
* *Error Handling:* Built-in logic to handle invalid city names or API failures gracefully.
* *Visual Feedback:* Dynamic weather icons that change based on current atmospheric conditions.

## 📖 How it Works
1. The user enters a city name in the search bar.
2. An asynchronous fetch() request is sent to the OpenWeatherMap API.
3. The JSON response is parsed and dynamically updated in the DOM without page reload.
4. CSS transitions ensure a smooth user experience during data updates.
